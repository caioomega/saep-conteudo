------------------------------------------------------------------
 O QUE É SESSÃO?
------------------------------------------------------------------
  Cada página PHP "esquece" tudo quando termina. Então como o
  sistema lembra que você fez login?
  -> com a SESSÃO. É uma "gaveta" no servidor, uma pra cada
     navegador, onde você guarda coisas:

       session_start();                    // abre a gaveta
       $_SESSION['usuario_nome'] = "Maria"; // guarda
       echo $_SESSION['usuario_nome'];      // lê (em qualquer página)
       session_destroy();                   // joga tudo fora (logout)

  REGRA: session_start() tem que vir ANTES de qualquer HTML ou echo.
  Toda página que usa $_SESSION precisa do session_start()
  (o verifica_login.php já faz isso).

------------------------------------------------------------------
 POR QUE A SENHA FICA "ESQUISITA" NO BANCO?
------------------------------------------------------------------
  Por segurança, a senha é guardada CRIPTOGRAFADA (hash).
    password_hash("123", PASSWORD_DEFAULT)   -> cria o hash
    password_verify("123", $hash_do_banco)   -> confere (true/false)

  Pra criar usuário no .sql, gere o hash no gerar-hash.php e cole.

  PLANO B (se tiver com pressa e a prova não exigir criptografia):
  guardar a senha normal e comparar direto:
     INSERT INTO usuarios (nome, login, senha) VALUES ('Admin','admin','123');
     ...
     if ($usuario && $senha == $usuario['senha']) { ... }
  Funciona, mas é INSEGURO. Se der tempo, use o password_hash.
  Se usar o plano B, troque também no login.php a linha do
  password_verify.
