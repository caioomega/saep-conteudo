  SAEP - PROVA PRÁTICA - MATERIAL DE CONSULTA (OFFLINE)
==================================================================

Oi! Esta pasta tem TUDO que você provavelmente vai precisar na prova
prática do SAEP (Desenvolvimento de Sistemas), funcionando sem internet.

Tudo aqui é feito com:
  - XAMPP  (programa que já está instalado em C:\xampp)
  - PHP    (a linguagem que roda no servidor)
  - MySQL  (o banco de dados, onde as informações ficam guardadas)
  - HTML, CSS e JavaScript (o que aparece na tela)

------------------------------------------------------------------
 COMO A PROVA PRÁTICA COSTUMA SER
------------------------------------------------------------------
A prova dá uma "situação-problema" (ex.: uma empresa precisa de um
sistema pra controlar o estoque) e pede ENTREGAS. As mais comuns:

  1. DER (desenho do banco de dados)  ............ ver pasta 03
  2. Script SQL que cria o banco e coloca
     pelo menos 3 registros em cada tabela ....... ver pasta 02 e 11
  3. Requisitos funcionais ....................... ver pasta 10
  4. Casos de teste .............................. ver pasta 10
  5. Lista de infraestrutura (SO, programas,
     linguagem, banco que você usou) ............. ver pasta 10
  6. As telas do sistema funcionando:
       - Login (e mostrar o nome de quem entrou + botão sair)
       - Tela principal com os menus
       - Cadastro de produto (listar, buscar, inserir, editar,
         excluir, com validação)
       - Gestão de estoque (lista em ordem alfabética usando um
         ALGORITMO de ordenação, entrada/saída, data, e ALERTA
         quando o estoque fica abaixo do mínimo)
     ............................................ ver pasta 11

LEIA COM ATENÇÃO O QUE A SUA PROVA PEDE. O tema pode mudar (pode ser
biblioteca, oficina, escola, hospital...), mas a ESTRUTURA é quase
sempre a mesma. Aí é só trocar "produto" pela coisa da sua prova.

------------------------------------------------------------------
 PLANO PARA O DIA DA PROVA (passo a passo)
------------------------------------------------------------------
 [ ] 1. Leia a prova inteira antes de começar. Anote as tabelas e
        campos que ela pede.
 [ ] 2. Ligue o Apache e o MySQL no XAMPP (pasta 01).
 [ ] 3. Faça o DER (pasta 03). Pode ser no papel se deixarem, ou no
        MySQL Workbench.
 [ ] 4. Copie o banco.sql da pasta 11, troque nomes de tabelas e
        campos pelo que a prova pede, e rode no phpMyAdmin.
 [ ] 5. Copie a pasta 11 inteira pra C:\xampp\htdocs\ com o nome do
        seu projeto e vá adaptando tela por tela.
 [ ] 6. Teste tudo no navegador: login, cadastrar, editar, excluir,
        buscar, entrada, saída, alerta.
 [ ] 7. Preencha os modelos da pasta 10 (requisitos, casos de teste,
        infraestrutura).
 [ ] 8. Entregue do jeito que pedirem (geralmente uma pasta com seu
        nome contendo tudo). Confira que o .sql está junto!

Dica de ouro: faça funcionar primeiro, deixe bonito depois.
Um sistema feio que funciona vale MUITO mais que um bonito quebrado.
