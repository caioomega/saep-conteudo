  histórico.

------------------------------------------------------------------
 COMO OS DADOS FICAM SALVOS?
------------------------------------------------------------------
  No localStorage: uma memória do próprio navegador. Se fechar e
  abrir de novo, os dados continuam lá (no mesmo navegador).
    localStorage.setItem("chave", "texto")   salvar
    localStorage.getItem("chave")            ler
    JSON.stringify(obj) / JSON.parse(texto)  objeto <-> texto

  O login fica no sessionStorage (some quando fecha o navegador).

------------------------------------------------------------------
 COISAS DE JAVASCRIPT QUE ESTE EXEMPLO ENSINA
------------------------------------------------------------------
  addEventListener("submit", ...)   rodar algo quando envia o form
  evento.preventDefault()           não deixar a página recarregar
  lista.find(p => p.id === 3)       achar um item
  lista.filter(p => p.id !== 3)     tirar um item (excluir)
  lista.push(obj)                   adicionar item (cadastrar)
  lista.map(...).join("")           transformar lista em HTML
  elemento.innerHTML = "..."        mudar o conteúdo da tela
  elemento.style.display = "none"   esconder
